# Milestone 3 — Candidate Profiler Tool

## 1. Overview
Leverages LLM reasoning to map candidate resumes into role, seniority, and management taxonomies.

## 2. Key Components
- **`profiler.py`**: Executes prompt templates loader extracting taxonomy variables.
- **`candidateClient.js`**: Node gateway interface wrapper.
- **`prompts/`**: Structured system guidelines.
