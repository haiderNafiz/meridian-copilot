# Milestone 5 — Knowledge Platform (RAG)

## 1. Overview
Aggregates candidate and job description indexes. Implements local chunking configurations, MockVectorStore, and Cosine ranking.

## 2. Key Components
- **`chunking.py`**: Character-based chunk splitter.
- **`mock_store.py`**: Pre-populates vector records in-memory for testing.
- **`retrievalClient.js`**: Node gateway adapter.
